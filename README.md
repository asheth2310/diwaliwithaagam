# Happy Diwali from Aagam

A personal Diwali website: a cinematic intro (cartoon Aagam lights a rocket, it climbs and booms), then a festive page with a video message, five diyas, a mithai box, fireworks, a rangoli to draw, a greeting card and a last rocket to light.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Host on Vercel
1. Go to vercel.com, choose **Add New → Project**, and import this repository.
2. Framework preset: **Other**. Leave build command and output directory empty.
3. Deploy.

## Host on GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Save. The site appears at `https://<username>.github.io/<repo>/` within a minute or two.
